BACHILLERATO EN DESARROLLO DE SOFTWARE

PRIMER AÑO

El primer año funciona como la base de toda la carrera. El estudiante comienza aprendiendo a pensar de manera lógica y estructurada para transformar problemas reales en soluciones que posteriormente puedan ser programadas.

1. Elaboración de algoritmos usando lógica de programación

Código: BTVDS 1.1
Duración: 108 horas / 6 semanas.

Introducción a la lógica de programación y resolución de problemas mediante algoritmos.

2. Identificación de requerimientos para diseñar o modificar sistemas informáticos

Código: BTVDS 1.2
Duración: 90 horas / 5 semanas

Análisis de las necesidades del usuario antes de desarrollar un sistema.

3. Diseño de aplicaciones multimedia

Código: BTVDS 1.3
Duración: 72 horas / 4 semanas.

Creación y organización de contenidos multimedia para aplicaciones y proyectos digitales.

4. Elaboración de manual de sistemas de calidad para el desarrollo de software

Código: BTVDS 1.4
Duración: 108 horas / 6 semanas.

Introducción a la calidad, documentación y organización de los sistemas de software.

5. Desarrollo de páginas web

Código: BTVDS 1.5
Duración: 108 horas / 6 semanas.

Desarrollo de páginas web utilizando tecnologías como HTML y CSS.

6. Conversación en inglés sobre sistemas informáticos y desarrollo de páginas web

Código: BTVDS 1.6
Duración: 72 horas / 4 semanas.

Aprendizaje de vocabulario y comunicación en inglés relacionado con informática.

7. Emprendedurismo colaborativo

Código: BTVDS 1.7
Duración: 72 horas / 4 semanas.

Desarrollo de habilidades de emprendimiento, creatividad y trabajo en equipo.

8. Proyecto tecnológico de desarrollo de páginas web

Código: BTVDS 1.8
Duración: 72 horas / 4 semanas.

Integración de los conocimientos del año mediante un proyecto tecnológico.
